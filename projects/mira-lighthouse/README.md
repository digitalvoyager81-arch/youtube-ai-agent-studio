# Мира и Пых — 3D-мультик (9:16, 60 сек)

Мультфильм по раскадровке «Маяк»: 6 сцен по 10 секунд, вертикальный формат
1080×1920, 30 fps, без текста и надписей. Всё — персонажи, окружение, свет,
музыка — генерируется кодом (Remotion + Three.js + numpy), без внешних ассетов.

| # | Сцена | Что происходит |
|---|-------|----------------|
| 1 | Потеря | Сумерки у подножия маяка. Мира приседает к тусклому Пыху, тот показывает на погасшую верхушку маяка; камера поднимается к ней. |
| 2 | Путь к пещере | Закат сквозь грозовые тучи. Мира протягивает ладонь, Пых прыгает ей на плечо и показывает на прибой и грот; камера едет перед героями. |
| 3 | Спуск в бездну | Ракурс сверху: Мира шагает по скользким уступам, прижимая дрожащего Пыха, капли и мерцание на камнях. |
| 4 | Обретение искры | Крупный план: хрустальная чаша, касание — вспышка, золотые лучи (god rays), Пых начинает сиять. |
| 5 | Возвращение на маяк | Буря, дождь, молнии. Смотритель встречает героев, Пых влетает в линзу Френеля, луч прорезает шторм и освещает корабли. |
| 6 | Тепло единства | Уютная комната у круглого окна, звёздный океан, медленный отъезд камеры. |

## Структура

```
src/
  Root.tsx, Movie.tsx   композиция, склейка сцен, затемнения, виньетка, звук
  characters.tsx        Мира, Пых, Смотритель, фонарь (позы задаются параметрами)
  world.tsx             маяк, корабли, линза Френеля
  fx.tsx                небо, море, камни, облака, дождь, свечение, лучи света
  scenes/Scene1..6.tsx  анимация каждой сцены (камера, позы по кадрам)
scripts/
  make_music.py         процедурный саундтрек -> public/soundtrack.wav
  sheet.sh              контактный лист превью-кадров
```

## Сборка

```bash
npm install
npm run music                     # саундтрек (нужен python3 + numpy)
npm run dev                       # Remotion Studio
npm run render                    # out/mira-lighthouse.mp4
```

В облачной среде без GPU используется программный WebGL (`swangle`,
см. `remotion.config.ts`). Если Remotion не может скачать свой Chrome,
укажите локальный браузер: `REMOTION_BROWSER=/path/to/chrome-headless-shell`.
