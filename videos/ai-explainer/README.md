# Искусственный интеллект — объясняющее видео

Видео ~2 минуты, 1920×1080, 30 fps, озвучка мужским голосом `ru-RU-DmitryNeural` (Edge TTS). Сделано на Remotion по скиллу `remotion-video`.

## Сцены

| # | Сцена | О чём |
|---|-------|-------|
| 1 | Вступление | Лицо, рекомендации, перевод → «Как работает ИИ?» |
| 2 | Что такое ИИ | Правила + данные → ответы vs данные + ответы → правила |
| 3 | Данные | Кошка или собака, тысячи фото, картинка как таблица чисел |
| 4 | Нейронная сеть | Слои нейронов, вычисление одного нейрона, ответ сети |
| 5 | Обучение | Веса подстраиваются, точность растёт с 50% до 98% |
| 6 | Масштаб | Языковые модели: триллионы слов, сотни миллиардов весов |
| 7 | Итог | Математика, данные, примеры + призыв подписаться |

## Команды

```bash
npm install
npm run audio    # озвучка → public/audio/*.mp3 и src/audioConfig.ts
npm run dev      # Remotion Studio для предпросмотра
npm run render   # → out/video.mp4
```

Текст озвучки — в `scripts/generate_audio.py` (`SCENES`). Чтобы перезаписать реплику, удалите её `public/audio/<id>.mp3` и запустите `npm run audio`: длительности сцен и тайминги субтитров обновятся сами.

Анимации привязаны к началу предложений озвучки (`scene.sentences[i].from`), поэтому после правки текста они остаются синхронными.
